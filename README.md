# shiori

よく使う CLI コマンドを登録・検索・実行・管理するためのツール。

栞（しおり / bookmark）のように、プロジェクトごとのコマンドに目印をつけて、
安全に呼び出せることを目指します。CLI / TUI（Bubble Tea）/ GUI（Wails）の
3 つの入り口を持ちますが、ドメインロジックは単一のコアパッケージに閉じ込め、
どの UI にも依存させません。

> 🚧 現在は設計フェーズ（M0）です。まだ動くコードはありません。

## 準拠する基準

- Google Go Style Guide（Style Guide / Style Decisions / Best Practices）
- Go Code Review Comments
